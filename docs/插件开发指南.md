## 插件基类架构

### BasePlugin 类结构

```
BasePlugin (QWidget, ABC)
├── 插件元数据 (PLUGIN_INFO)
│   ├── name: 插件名称
│   ├── description: 插件描述
│   ├── version: 版本号
│   ├── author: 作者
│   ├── category: 分类
│   └── icon: 图标
│
├── 抽象方法 (必须实现)
│   └── get_widget() -> QWidget
│
├── 生命周期方法 (可选覆盖)
│   ├── on_init() - 初始化回调
│   ├── on_activate() - 激活回调
│   ├── on_deactivate() - 停用回调
│   └── on_theme_changed(is_dark) - 主题切换回调
│
├── UI 辅助方法
│   ├── setup_standard_layout() - 创建标准布局
│   ├── create_group_box(title) - 创建分组框
│   ├── create_button(text, style_type) - 创建按钮
│   └── create_description_section(html) - 创建说明区域
│
└── 工具方法
    ├── show_info(message, title) - 信息提示
    ├── show_warning(message, title) - 警告提示
    ├── show_error(message, title) - 错误提示
    ├── log_debug(message) - 调试日志
    ├── log_info(message) - 信息日志
    └── log_error(message) - 错误日志
```

## 创建新插件

### 方法 1: 使用插件模板

1. 复制 `plugins/_plugin_template.py` 文件
2. 重命名为 `your_plugin_name.py`
3. 根据需要修改插件内容

### 方法 2: 从零开始

```python
from PyQt6.QtWidgets import QVBoxLayout, QLabel
from src.plugins.base_plugin import BasePlugin

class MyPlugin(BasePlugin):
    PLUGIN_INFO = {
        "name": "我的插件",
        "description": "插件描述",
        "version": "1.0.0",
    }

    def __init__(self):
        super().__init__()
        self._setup_ui()

    def get_widget(self):
        return self

    def _setup_ui(self):
        layout = self.setup_standard_layout()
        label = QLabel("Hello, World!")
        layout.addWidget(label)
```

## 现有插件迁移

### 迁移步骤

将现有插件迁移到新架构的步骤：

#### 1. 添加插件元数据

在类中添加 `PLUGIN_INFO` 字典：

```python
# 旧代码
class MyPlugin(BasePlugin):
    def __init__(self):
        super().__init__("插件名", "插件描述")

# 新代码
class MyPlugin(BasePlugin):
    PLUGIN_INFO = {
        "name": "插件名",
        "description": "插件描述",
        "version": "1.0.0",
        "author": "",
    }

    def __init__(self):
        super().__init__()
```

#### 2. 使用标准布局辅助方法

```python
# 旧代码
def _setup_ui(self):
    main_layout = QVBoxLayout(self)
    main_layout.setContentsMargins(0, 0, 0, 0)

    main_scroll = QScrollArea(self)
    main_scroll.setWidgetResizable(True)
    main_scroll.setFrameShape(QFrame.Shape.NoFrame)

    scroll_widget = QWidget()
    layout = QVBoxLayout(scroll_widget)
    layout.setContentsMargins(20, 20, 20, 20)
    # ...

# 新代码
def _setup_ui(self):
    layout = self.setup_standard_layout()
    # 直接使用 layout 添加组件
```

#### 3. 移除内联样式

```python
# 旧代码
btn = QPushButton("按钮")
btn.setStyleSheet("""
    QPushButton {
        background-color: #3498db;
        color: white;
        ...
    }
""")

# 新代码 - 使用辅助方法
btn = self.create_button("按钮", "primary")
```

#### 4. 使用统一的日志方法

```python
# 旧代码
from src.utils.logger import logger
logger.info("操作成功")

# 新代码
self.log_info("操作成功")
```

#### 5. 使用统一的提示框方法

```python
# 旧代码
from PyQt6.QtWidgets import QMessageBox
QMessageBox.information(self, "提示", "操作成功")

# 新代码
self.show_info("操作成功")
```

## 最佳实践

### 1. 使用辅助方法减少重复代码

```python
# 推荐
settings_group = self.create_group_box("设置")
action_btn = self.create_button("执行", "success")

# 不推荐
settings_group = QGroupBox("设置")
settings_group.setStyleSheet("...")
action_btn = QPushButton("执行")
action_btn.setStyleSheet("...")
```

### 2. 使用插件元数据

```python
# 推荐
class MyPlugin(BasePlugin):
    PLUGIN_INFO = {
        "name": "插件名",
        "description": "描述",
        "version": "1.0.0",
    }

# 不推荐
class MyPlugin(BasePlugin):
    def __init__(self):
        super().__init__("插件名", "描述")
```

### 3. 正确处理异常

```python
def on_action_clicked(self):
    try:
        # 业务逻辑
        result = do_something()
        self.log_info("操作成功")
    except Exception as e:
        self.log_error(f"操作失败: {e}")
        self.show_error(f"操作失败: {e}")
```

### 4. 利用生命周期钩子

```python
def on_activate(self):
    """插件激活时执行"""
    super().on_activate()
    # 加载配置、初始化资源等

def on_deactivate(self):
    """插件停用时执行"""
    super().on_deactivate()
    # 保存状态、释放资源等
```

## API 参考

### PLUGIN_INFO 字段说明

| 字段 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| name | str | 是 | - | 插件名称 |
| description | str | 是 | - | 插件描述 |
| version | str | 否 | "1.0.0" | 版本号 |
| author | str | 否 | "" | 作者名 |
| category | str | 否 | "" | 分类 |
| icon | str | 否 | "" | 图标名 |

### UI 辅助方法

#### setup_standard_layout()

创建标准布局结构（带滚动区域）。

**返回值**: `QVBoxLayout` - 内容区域的布局对象

#### create_group_box(title: str) -> QGroupBox

创建标准样式的分组框。

**参数**:
- `title`: 分组框标题

**返回值**: `QGroupBox` 实例

#### create_button(text: str, style_type: str = "primary") -> QPushButton

创建标准样式的按钮。

**参数**:
- `text`: 按钮文本
- `style_type`: 按钮样式类型
  - `"primary"` - 蓝色（主要操作）
  - `"success"` - 绿色（成功操作）
  - `"warning"` - 橙色（警告操作）
  - `"danger"` - 红色（危险操作）
  - `"info"` - 灰色（信息操作）
  - `"secondary"` - 浅灰（次要操作）

**返回值**: `QPushButton` 实例

#### create_description_section(html_content: str) -> tuple

创建可折叠的插件说明区域。

**参数**:
- `html_content`: 说明内容的 HTML 文本

**返回值**: `(header_layout, content_text, toggle_btn, scroll_area)`

### 工具方法

#### show_info(message: str, title: str = "提示")

显示信息提示框。

#### show_warning(message: str, title: str = "警告")

显示警告提示框。

#### show_error(message: str, title: str = "错误")

显示错误提示框。

#### log_debug(message: str)

记录调试日志。

#### log_info(message: str)

记录信息日志。

#### log_error(message: str)

记录错误日志。

## 示例插件

### 最小插件示例

```python
from PyQt6.QtWidgets import QVBoxLayout, QLabel
from src.plugins.base_plugin import BasePlugin

class MinimalPlugin(BasePlugin):
    PLUGIN_INFO = {
        "name": "最小示例",
        "description": "一个最小化的插件示例",
    }

    def __init__(self):
        super().__init__()
        self._setup_ui()

    def get_widget(self):
        return self

    def _setup_ui(self):
        layout = self.setup_standard_layout()
        label = QLabel("这是一个最小插件示例！")
        layout.addWidget(label)
```
